# From Exposure to Pattern Recognition

Most language apps are designed to feel productive.

Streaks fill. Lessons complete. Progress bars advance.

Recognition is not the same as internalization. Seeing a form and knowing you've seen it before is a different skill from producing it. Or hearing it and understanding it in real time. That gap is where most language learning fails.

VerbBoard is not trying to feel easy to use.

---

Every verb has a board: a conjugation table across tenses, persons, and numbers, with example sentences below. Russian past tense has a consistent structure across persons. Hebrew conjugation is determined entirely by the verb's binyan. Spanish verb endings carry person and number, often making the pronoun unnecessary.

The table makes the system visible. Not isolated forms to memorize, but a pattern to recognize. Once a learner understands how one verb in a group behaves, the next one in the same group costs less.

The example sentences are generated by a language model. They vary -- some are clean, some are awkward. They are there to show the form in a grammatical context.

---

Practice sessions are 3, 6, or 9 verbs, chosen at the start. Sessions earn a badge on completion.

Each verb has a minimum audio play count before the learner can advance -- configurable, never zero.

Reading forms and hearing them spoken are different skills. The requirement ensures the learner has done both before moving on.

VerbBoard provides the audio. It does not yet listen back.

Any verb in the session can be skipped. Skip marks it as known and removes it from the session -- a judgment call about where work is still needed, not a bypass.

---

Example sentences are in the target language. When the interface language differs, inline translation is available as an option, not a default.

Immediately reading the translation skips any engagement with the target-language sentence. That engagement is where comprehension develops.

Translation is there when you need it.

---

VerbBoard currently supports English, Russian, Hebrew, and Spanish. Learners choose the study language and the interface language independently. The set of study languages will continue to grow; interface languages are intentionally kept limited. Progress syncs on sign-in. Progress made before signing in is never overwritten -- on first login, local history merges with the server.
