# Learning Through Pattern Recognition

Most language-learning products optimize for visible progress.

Lessons complete. Progress bars fill. Streaks grow.

VerbBoard focuses on something more fundamental: becoming familiar with verb forms.

Recognition comes before production.

Before you can confidently produce a verb, you need to recognize its forms, hear them repeatedly, and connect them to meaning and real examples.

That is why VerbBoard emphasizes complete conjugation tables, audio, contextual examples, and repeated exposure.


## Every Verb Has a Board
Every verb has a board: a conjugation table across tenses, persons, and numbers, with example sentences below. Russian past tense has a consistent structure across persons. Hebrew conjugation is determined entirely by the verb's binyan. Spanish verb endings carry person and number, often making the pronoun unnecessary.

The board makes the system visible.
Not isolated forms to memorize, but a pattern to recognize.
Once a learner understands how one verb in a group behaves, the next verb following the same pattern requires much less effort.

The example sentences are generated by a language model. They vary - some are clean, some are awkward. These could be gradually imporoved. Most importantly, example sentences place each form in grammatical context. They exist to demonstrate how the verb is actually used, not to provide another isolated translation.


## Practice Reinforces Recognition

Practice sessions consist of 3, 6, or 9 verbs. Completing a session earns a learning badge.

Before advancing, learners must listen to each verb's audio a minimum number of times. The threshold is configurable, but never zero.

Reading a verb and hearing it spoken develop different kinds of familiarity. The listening requirement encourages both before moving on.

VerbBoard provides the audio.

It does not yet listen back.

Any verb in a session can be skipped. Skipping marks it as known and removes it from the current session. That decision is left to the learner - it reflects where they believe additional practice is still needed.

## Translation Supports Learning

Example sentences remain in the target language.

When the interface language differs, an inline translation is availablexi - but only when requested.

Translation establishes meaning.

Pattern recognition builds understanding and helps learners retain new material.

Immediately reading the translation reduces engagement with the target - language sentence. VerbBoard therefore treats translation as support, not as the primary learning experience.

## Looking ahead
Future versions of VerbBoard will likely introduce more production-oriented practice. But production makes sense only after learners have become familiar with the forms themselves.

VerbBoard currently supports English, Russian, Hebrew, and Spanish. Learners choose the study language and the interface language independently. The set of study languages will continue to grow; interface languages are intentionally kept limited.
